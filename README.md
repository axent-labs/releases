# The Microsoft Store's copy of the installer

This branch is served by GitHub Pages, so the Microsoft Store can download AXENT POS's Windows installer from a fixed address with no redirect, which release downloads do not have. It holds only the installer under each version's own folder, the current one and the one before it:

    https://axent-labs.github.io/releases/store/<version>/AXENT-POS-<version>-setup.exe

Each file is the same as the one on that version's release. Every release, for every system, is on the releases page.
